# ADR-003: Synthetic data policy and provenance

Status: Accepted
Date: 2026-10-06
Spec fields: `synthetic_data_policy`, `data.decontamination`

## Context

Many high-quality public datasets were generated by larger models. Examples: SmolTalk, MetaMathQA, OpenMathInstruct-2, NuminaMath-CoT, Cosmopedia, UltraFeedback. Separately, the reasoning and preference stages need self-generated, verified data. We need a clear line on what counts as "teacher data" for V2.

## Decision
- **Allowed:**
  - Public datasets, including public synthetic datasets originally generated by larger models.
  - Data generated by **LiteGPT checkpoints themselves**, kept only if it passes a verifier: answer match for math, unit tests in a sandbox for code.
- **Not allowed in V2:** running external or larger teacher models ourselves to generate data. Teacher-generated data is a separate, later experiment.
- **Provenance is mandatory** in every data manifest. It records:
  - `source`, `revision`, `original_generator` (if synthetic), `license`, `terms_of_use`.
  - `verifier`, for self-generated data.
  - `generator: litegpt-v2@<checkpoint>`, for self-generated data.
- **Licence auditing:** every source is entered into `docs/data_licenses.md` before use. Data whose origin carries terms-of-use restrictions (e.g. outputs of commercial APIs) is flagged explicitly. That feeds the model-licence decision (ADR-004).
- **Decontamination:** a 13-gram overlap filter of all SFT, reasoning and DPO data against every evaluation set, with overlap statistics stored as records. Pretraining data gets a spot-check.

## Alternatives rejected
- **No model-generated data at all:** it would remove the best available instruction and reasoning datasets for this scale.
- **Running open teacher models locally:** it costs scarce GPU time, adds licensing complexity, and is deferred to a separate experiment.

## Consequences
- Reports can attribute post-training gains to public data vs self-generated, verified data.
- The model card lists the provenance of every dataset.

## Evidence
- Pending M1 and M4: data manifests, `docs/data_licenses.md`, decontamination records.
