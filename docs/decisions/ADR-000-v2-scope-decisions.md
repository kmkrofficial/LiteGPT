# ADR-000: V2 scope decisions (D1–D4)

Status: Accepted
Date: 2026-10-06
Spec fields: `model`, `environment`, `training.pretraining`, `training.extension_gate`, `synthetic_data_policy`, `licensing`

## Context

LiteGPT V1 is a GPT-2 Small (124.5M) reimplementation, trained on about 9.8B FineWeb-Edu tokens and fine-tuned on Alpaca. V2 aims to be a usable small language model trained on a single RTX 4090 Laptop GPU (16 GB). Before implementation, four project-level decisions were made. This ADR records them. Detailed ADRs follow for each topic.

## Decisions

| ID | Decision | Detail |
|---|---|---|
| D1 | Use the **28-layer / ~201.4M** architecture. Pretrain on **~10B tokens (~7 days)** first. Extend toward **15B** only if the pre-registered gate passes. | ADR-001, [ADR-005](ADR-005-model-architecture.md) |
| D2 | ~~Python 3.11 + PyTorch 2.9 + CUDA 12.8~~ → **Python 3.12 + uv + PyTorch 2.14.1 (cu130)**, see ADR-006. `flash-attn` is an optional fast path; **SDPA is the mandatory fallback**. Try `torch.compile`; **WSL2 is the preferred production training/compile environment**. | [ADR-002](ADR-002-environment-and-attention-backends.md) |
| D3 | **Public datasets are allowed**, including public synthetic datasets originally generated by larger models. **We do not run external teacher models ourselves for V2.** Self-generated data must come from LiteGPT checkpoints and pass a verifier. Provenance and licence auditing are enforced. | [ADR-003](ADR-003-synthetic-data-and-provenance.md) |
| D4 | **The code is MIT**, with the required upstream copyright notice restored. **The model licence is not finalised** until every dataset licence is audited and compatibility is confirmed; that audit is a release gate. | [ADR-004](ADR-004-licensing.md) |

## Consequences

- These decisions are encoded in `docs/spec/v2.yaml` (currently `spec_version: 2.0.0-spec.5`).
- Every run records the spec version and the spec's sha256.
- Generated reports print the spec table and flag any run that deviates from it.
- Changing any decision requires a new ADR that supersedes the relevant one, plus a spec version bump.
